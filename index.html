Learning Machine

Machine learning is a branch of artificial intelligence where computers learn patterns from data to make predictions or decisions without explicit programming.

Supervised Learning: A type of machine learning where a model learns from labeled data (data with correct answers).

Reinforcement Learning: A type of machine learning where an agent learns by trial and error (rewards and penalties).

Unsupervised Learning: A type of machine learning where a model learns from unlabeled data (finds patterns by itself).
